# 高考必背文言文阶梯式背诵 Web App

专为个人打造的高考语文必背名篇**阶梯式背诵（Ladder Recitation）**移动端 Web App。
核心设计理念：**不打字、不考试、无判分压力，通过六阶心智提取（Active Recall）与 Emoji 视觉记忆锚点，将课文稳固刻入脑海。**

---

## 🌟 六阶背诵法（核心特色）

* **Level 0：完整原文**（通读全文，提供逐句现代汉语白话译文对照，一键自由显示/隐藏）
* **Level 1：少量挖空**（挖去 15%~25% 核心通假字与关键字词，在脑海中主动补全）
* **Level 2：中度挖空**（挖去 35%~45% 骨干实词，轻微扰动防止机械记忆位置）
* **Level 3：大量挖空**（挖去 60%~70% 词语，依靠语感与语义连贯性进行深层回忆）
* **Level 4：骨架背诵**（极限背诵：仅保留每句首字与标点符号，全凭心智提取）
* **Level 5：🌟 Emoji 视觉记忆锚点**（文字全隐，仅提供动作、场景与因果相关的 Emoji 符号流，如 `🌳 ➔ 📏 ➔ 🔥 ➔ 🔄 ➔ ⭕️` 联想出 `木直中绳，輮以为轮，其曲中规`）

### 辅助记忆功能
1. **轻触探看**：任何单个挖空 `[＿]` 点击即可立即揭晓该词，不打断整句背诵节奏；
2. **⭐ 标记易忘**：点击句子右侧星标，系统自动记录薄弱点，并在各等级挖空中**优先挖除**；
3. **分段与逐句循环**：支持长篇按段落各个击破，点击 `[🔁 换一组空]` 随时重新刷新记忆；
4. **防休眠番茄钟**：顶部常驻 `🍅 25:00`，采用时间戳差值计算，在 iOS 锁屏或挂起切回后毫秒级校准恢复；
5. **纯本地持久化**：使用 localStorage 保存每篇进度，支持一键导出/导入 JSON 备份迁移。

## 🛡️ 极致向下兼容标准

* **硬性最低兼容**：**iPod touch 5 + iOS 9.3.5 Safari (320×568)**
* **纯正 ES5 规范**：零 ES6+ 语法，无箭头函数、无模板字符串、无 `let/const`、无 `fetch()`
* **纯 CSS 弹性流式排版**：无 CSS Grid，无 Flexbox `gap`，全面适配 320px 极限小屏
* **零外部构建依赖**：纯静态资源，双击即开，无需 Node / Webpack / Vite 编译。
